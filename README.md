# Gunshade // Original Graphics Co-op

Эта версия возвращает исходный прикреплённый `gunshade_lev_edisen.html` без перерисовки и без замены HUD, карты, управления или визуальных эффектов. В оригинальный script-блок добавлен только сетевой слой на WebSocket.

## Что осталось из оригинала

Карта, стены, камера, HUD, HP, пистолет, патроны, перезарядка, нож, базука, аптечка, броня, враги, столкновения, кровь, кровавые пятна, blood jets, частицы, взрывы и исходные touch-контролы остаются из прикреплённого файла.

## Что добавлено

Два игрока подключаются к одной Render-ссылке. Первый получает место Игрока 1, второй — Игрока 2. Сетевой слой передаёт состояние игрока, оружие, HP и боевые события, а удалённый игрок отображается поверх оригинального рендера. При одном подключённом игроке оригинальная игровая логика ждёт второго, чтобы матч начинался одновременно.

## Управление

Оригинальное управление сохранено: `WASD`/стрелки или левый джойстик — движение, мышь/правый touch-жест — прицел, `ЛКМ` или `FIRE` — стрельба, `Q` — смена оружия, `E` — подбор предметов.

## Render

```text
Build Command: npm install
Start Command: npm start
Health Check Path: /health
```

Render автоматически передаёт `PORT`. Сервер слушает `0.0.0.0`, а WebSocket использует `/ws` на том же домене.

## Файлы

- `public/index.html` — исходный HTML Gunshade плюс сетевой слой, без новой стилизации.
- `server.js` — двухместный relay-сервер.
- `reference/gunshade_lev_edisen.html` — отдельная копия исходного файла.
- `render.yaml` — настройки Render.
- `test/server.test.js` — проверка двух подключений и relay состояния.
